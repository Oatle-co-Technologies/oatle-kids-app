# Animal Adventure sound sources

All nine clips are genuine animal recordings downloaded from Wikimedia Commons. The app uses the matching `.mp3` files: compatibility copies normalized for consistent playback volume. The original `.ogg` source files are retained for provenance.

- dog.ogg — [Ladrido perro.ogg](https://commons.wikimedia.org/wiki/File:Ladrido_perro.ogg), CC0
- cat.ogg — [Meow.ogg](https://commons.wikimedia.org/wiki/File:Meow.ogg), Dan Crosby, CC BY-SA 3.0
- cow.ogg — [Mudchute cow 1.ogg](https://commons.wikimedia.org/wiki/File:Mudchute_cow_1.ogg), Secretlondon, CC BY-SA 3.0
- sheep.ogg — [Sheep bleating.ogg](https://commons.wikimedia.org/wiki/File:Sheep_bleating.ogg), earthcalling, public domain
- elephant.ogg — [Elephant voice - trumpeting.ogg](https://commons.wikimedia.org/wiki/File:Elephant_voice_-_trumpeting.ogg), CC0

- horse.ogg — [Wiehern.ogg](https://commons.wikimedia.org/wiki/File:Wiehern.ogg), Hü, public domain.
- pig.ogg — [Mudchute pig 2.ogg](https://commons.wikimedia.org/wiki/File:Mudchute_pig_2.ogg), Secretlondon, [CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/).
- duck.ogg — [Anas platyrhynchos - Mallard - XC62258.ogg](https://commons.wikimedia.org/wiki/File:Anas_platyrhynchos_-_Mallard_-_XC62258.ogg), Jonathon Jongsma, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
- chicken.ogg — [Chickens demanding food.ogg](https://commons.wikimedia.org/wiki/File:Chickens_demanding_food.ogg), alys, public domain.

New MP3s are mono 44.1 kHz / 96 kbps, loudness normalized to -18 LUFS with a -2 dB true-peak target; chicken shortened to the first five seconds. Adapted recordings retain the source licence. Original Ogg recordings are retained unmodified.
